
# Violet — Purple Animated Website

A modern, responsive website with a premium dark-purple theme, smooth animations, and a clean user interface.

## Features

- Modern dark-purple design
- Responsive layout for mobile, tablet, and desktop
- Animated icons and hover effects
- Smooth scrolling and reveal animations
- Hero section with dashboard preview
- About and services sections
- Animated statistics
- Contact form demo
- Mobile-friendly navigation

## Requirements

- Node.js 18 or newer
- npm

## Installation

1. Open the project folder in your terminal.
2. Install the dependencies:

```bash
npm install
```

3. Start the website:

```bash
npm start
```

4. Open this address in your browser:

```text
http://localhost:3000
```

## Development

Run the development script:

```bash
npm run dev
```
